Mantis is a decoupled, sequential pipeline of security-focused AI skills designed for use with coding agents. Each skill handles one stage of the review lifecycle — from VCS history extraction through exploit chain construction, automated patch generation, and final risk-scored reporting. Install once, run against any codebase, and adapt the skills to your stack.

<Warning>
  **Use at your own risk.** Mantis is designed to generate and execute autonomously generated code. **Only run in isolated, restricted environments.** All findings must be manually verified by a security expert before being reported or acted upon.
</Warning>

## How Mantis Works

Mantis breaks a full security review into discrete, composable skills. Each skill is a prompt-driven agent that reads from and writes to a shared `workspace/` directory on disk. You run them sequentially in your coding agent CLI, or wrap them in a deterministic pipeline harness for CI/CD.

<Steps>
  <Step title="Install the skills">
    Add Mantis skills to your coding agent with one command:
    ```shell
    npx skills add google/mantis
    ```
  </Step>
  <Step title="Open your codebase in your agent">
    Launch Gemini CLI, Antigravity CLI, or any compatible coding agent from your project root.
  </Step>
  <Step title="Run the pipeline">
    Type the skill commands sequentially in your agent's prompt. Start with `/mantis-architecture` to build the knowledge base, then proceed through the pipeline stages.
  </Step>
  <Step title="Review the report">
    When `/mantis-report` completes, open `workspace/report/review_packet-latest.md` for your full, risk-scored security review packet.
  </Step>
</Steps>
